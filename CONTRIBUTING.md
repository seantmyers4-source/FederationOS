# Contributing

All changes require a traceable branch, pull request, authority reference, evidence reference, independent review, and passing checks. Do not commit restricted data or cross-OS canonical copies.

1. Identify the owning authority and approved directive.
2. Create a scoped branch.
3. update applicable manifests and provenance.
4. Run `python3 engineering/scripts/validate_bootstrap.py`.
5. Open a pull request using the template.
6. Do not merge until authorized by the competent authority.

Repository administration does not confer artifact ownership. Authority placeholders must remain placeholders until the owning authority supplies an approved record.
