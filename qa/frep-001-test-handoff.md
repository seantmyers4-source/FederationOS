# FREP-001 QA Test Handoff

QA & Certification is requested to independently verify:

1. Required bootstrap files and directory baseline exist.
2. JSON manifests parse and required schemas are present.
3. Public classification rules prohibit restricted content.
4. Secret and sensitive-pattern negative tests fail as expected.
5. Cross-OS records require canonical_copy=false.
6. Sovereign ownership language is consistent across artifacts.
7. No artifact claims canonical designation, publication, certification, release, or activation.
8. Pull-request validation executes successfully.
9. Missing platform controls are accurately represented as unverified.
10. Rollback and recovery are executable without history rewriting.

QA retains test design, finding disposition, and certification authority.
