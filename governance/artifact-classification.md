# Artifact Classification Policy Candidate

| Class | Public repository treatment |
|---|---|
| Public governance and schemas | Permitted after authority approval |
| Public references to cross-OS artifacts | Permitted through governed reference records |
| Another OS's canonical artifact | Prohibited; reference only |
| Restricted security/runtime evidence | Prohibited; external governed reference required |
| Personal, health, employment, financial, or family records | Prohibited |
| Secrets and credentials | Prohibited |
| Sensitive property/infrastructure information | Prohibited |
| Confidential commercial data | Prohibited |

A split public/private model is approved only in principle. No private companion repository is asserted or created by this candidate.
