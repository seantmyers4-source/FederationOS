# FederationOS

FederationOS coordinates governance shared across sovereign operating systems.

This repository is a **remediation candidate** under `FED-CC-RMD-FREP-001-001`. It is not canonically designated, Registry-published, QA-certified, released, or runtime-active.

## Sovereign ownership

FederationOS owns only FederationOS-governed canonical artifacts. Storage, hosting, custody, publication, or consumer binding does not create ownership. Cross-OS artifacts are referenced through governed records and may not be silently copied. Historical provenance must be preserved. Ownership transfer requires the extraordinary ratified process governed by FCI-001 and the provisional FCS-001 reference.

## Public boundary

This public repository must not contain secrets, credentials, personal, health, employment, financial, family, sensitive infrastructure, private runtime evidence, restricted security details, confidential commercial data, or another OS's canonical artifact. Restricted evidence requires a separately governed location that has not yet been established.

See [repository governance](governance/repository-governance.md), [classification](governance/artifact-classification.md), and [contributing](CONTRIBUTING.md).
