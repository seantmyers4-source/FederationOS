# Security Policy

Report suspected vulnerabilities privately through GitHub's security reporting capability when available; do not open a public issue containing exploit or secret details.

Never commit credentials, tokens, restricted evidence, personal data, sensitive infrastructure details, or confidential commercial material. Remove exposed credentials at the source and rotate them; deleting a commit is not sufficient.

Required controls—protected `main`, pull requests, independent review, required checks, force-push restrictions, deletion restrictions, bypass attribution, and secret scanning—remain subject to Security Governance and platform verification. Documentation here does not assert that a setting is enabled.
